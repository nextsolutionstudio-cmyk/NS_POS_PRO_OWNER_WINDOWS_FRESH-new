# NS POS PRO Developer Owner Windows
This Electron wrapper packages the same Owner HTML as Android v2.2.5. Cloudflare API URL and Owner account login are required. Does not bypass subscription or authenticate automatically. Payment deletion depends on deployed Cloudflare endpoints.
Run `npm install`, `npm run dist:win` or upload this folder to GitHub Actions to produce Windows Setup EXE and portable EXE. No EXE binaries are included. Code signing is recommended for distribution.
